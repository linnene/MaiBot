# 宿主互动策略委托

`proactive.delegate_interaction_policy` 默认 false。启用前，宿主须提供并启用 interaction_memory.active；不可用时不发送。

委托模式保留生活状态、休息、免打扰和用户每日硬上限，将间隔、话题价值与待回访判断交给宿主。没有生活候选时也可只检查宿主待回访事项。被宿主拒绝的候选不反复重试，不扣发送额度；平台确认仍沿用已有事件关联。早晚窗口优先于普通生活候选，重要日期独立分类。

开启后暂停旧连续话题整理和注入，避免双份状态；关闭则恢复原路径。没有数据库 schema 迁移。WebUI 最近互动显示使用插件环境时间，避免模拟/历史环境与机器时钟不一致。
