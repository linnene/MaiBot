# 自主联系与角色自己的提醒

## 已确认的方向

角色可以闲聊、聊完后补一句、问对方大概什么时候有空，也可以说忙完来找她。她有自己的提醒清单，能添加、更改、完成、取消和删除。提醒到时唤起角色重新考虑；可以放弃或延期，不是定时强发。用户没有回来时，允许偶尔换个话题再联系，并逐步退避。界面仅供查看，不提供人工纠正或替她编辑清单。

这些属于助手自己的意图，与从用户原话提取的事实、共同约定分开。现有可信身份、私聊保密、原始人设与短回复要求保留。亲昵、撒娇、轻微争宠和小情绪只属于已绑定的特殊关系，不改变其他人的普通朋友身份。

## 这批实现

独立 SDK 插件 `local.self-reminders` 暴露 `self_reminders` 工具，使用独立 SQLite 状态。状态流为 scheduled → reviewing → done / scheduled / waiting / uncertain / handled。新建同类同标题且时间相近的条目去重；更广泛的合并通过工具先查看再更新。原有记忆系统仍负责用户事实。

到期时有一次受限的内部考虑，只输出放弃、延期或联系意愿。联系送入既有互动准入、Planner 和 Replyer，不直接生成或发送 QQ 文案。插件调用现有模型路由，没有新增账号或模型服务。

保留每日联系预算、忙碌/结束状态、未回复退避和重复主题限制。最近二十分钟内产生的 afterthought，可在双方安静至少两分钟后补一句；仅在没有未回复主动消息时放宽普通闲聊的长间隔。其他意图沿用现有间隔。这些时间是首版可审查的工程默认值，不是人类行为研究结论。

未知排队结果、中断和超时进入 uncertain，不自动重试；明确未回复退避进入 waiting，待对方回来再考虑。新用户消息可撤销标记 cancel_on_reply 的意图；修改和取消提升版本。Host 为所有回复分段携带主动任务来源，发送前逐段验证实际任务与意图版本，避免引用上一条消息改变锚点后绕过撤销。

只读工作区显示事项、起因、到期时间和结果；排队明确标记为未确认发送，只有真实平台回执才标记发送。不把定时唤起、排队回执或测试 mock 当成真人观感验收。

## 默认边界与回滚

仅启用现有独占可信 QQ 私聊。没有到期事项时零新增模型调用。每天最多八次内部重新考虑、每分钟检查一次、最多五十个未处理事项，凌晨两点到早七点暂停唤起；普通联系仍共享宿主预算。联系提醒过期窗口六小时，角色待办七天，终态记录三十天。界面不提供变更或手动发送按钮。

保留部署前源码、插件锁、私有配置和一致性数据库备份。回滚源码时不回滚当前聊天和记忆数据。关闭插件即可停止新唤起；已到发送步骤的任务仍由源任务标识和撤销检查约束。

## 效果边界

已实现的是自主提醒能力和安全接入，不代表模型一定会主动调用工具，也不代表自然性已经改善。需观察实际工具采纳、补话是否相关、重联时机和用户感受。此次不开展额外付费对照、私聊语料外发或真实 QQ 测试发送。
