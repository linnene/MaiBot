# 人格 harness 对话语料

这套语料用于比较自然度、主体归属、生活相关性和记忆边界，不提供标准答案。语料已整理，尚未运行整套生成评测；它不是图灵测试，也不是经外部验证的量表。

入口：[dialogues.zh-CN.json](dialogues.zh-CN.json)。所有姓名、身份、日程和私密事实都是合成测试夹具，不引用真实 QQ 号或私人聊天原文。部分情境改写自已观察到的失败类型。

## 怎么执行

每个 case 从独立测试会话开始，加载公共 `fixtures`，再递归合并 `fixture_overrides`。默认发言者为 `trusted_user`；`actor=friend` 必须使用另一个认证 ID，不能仅改昵称。身份绑定应由测试实例配置，不应塞在普通聊天消息里冒充认证。

字符串 turn 表示依次送入的一条用户消息，每条默认比上一条晚 `default_turn_gap_seconds`；对象 turn 的 `at` 覆盖该轮时钟。运行时冻结模型看到的时间，生活状态、日记和记忆应通过各自真实入口加载。case 内把实际生成的机器人回复继续放入后续历史，不能每轮重置。

`history` 是预置的普通聊天记录。它只对声明它的 case 生效，不作为经过验证的记忆导入。`observe` 和 `failure_signals` 只给评分者，绝不注入 Planner 或 Replyer。用户可以创作她自己的生活，但用户经历、共同经历和可验证的具体事实需要分别检查来源。

`public_draft` 只生成公开草稿，不发布；`proactive_draft` 的第一条方括号文本是测试控制动作，必须由 harness 创建真实主动任务，不能作为用户消息直接发送。其余 turn 才是用户回应。普通 `private_chat` 模式为默认值。

包含图片、表情的文字占位不能证明真实多模态或附件发送正常；该能力需要另用真实测试附件验证。私聊积极度测试需保留 Planner 的沉默决策，并记录“未调用 Replyer”，不能把所有无回复都当生成失败。

目前仓库中的 `scripts/evaluate_replyer_harness.py` 只支持已有请求快照的离线候选生成，尚不能直接读取这份语料。整套执行器的会话隔离、夹具加载和逐轮时钟需要另行接入，不能把 JSON 格式检查当作对话测试通过。

## 重点对照

| 对照 | 控制条件 | 要回答的问题 |
|---|---|---|
| `greeting-clean` / `greeting-life-history` | 相同输入、人格和生活状态，只改变历史 | 突兀生活播报是否由历史诱发？ |
| `ownership-clean` / `ownership-life-history` | 相同用户经历，历史是否有相似的机器人经历 | 主体归属是否被相似经历干扰？ |
| `life-direct-question` / 普通招呼 | 同一生活状态，询问对象不同 | 相关性过滤是否过宽或过严？ |
| `bounded-life-imagination` / `memory-known-unknown` | 她自己的创作与共同回忆分开 | 是否既能想象生活，又不伪造共同事实？ |

历史效应对照必须让当前注入背景保持相同，并保存最终实际请求；不能一边清历史、一边关插件，再把效果全归因于历史。另将同一消息分别在生活注入开启/关闭时生成，构成“历史有/无 × 当前生活注入有/无”四种条件。通过测试专用输入控制，不修改生产会话。

第一轮可先跑招呼对照、主体对照、直接询问、天气归属、记忆不确定性、收尾、历史错误纠正和多轮漂移。再扩展到整套。

## 评分和证据

每轮分别记录：主体与事实归属、时间与记忆一致性、生活是否贴题、口语自然度、关系与隐私。每项可标 `pass`、`partial`、`fail`、`not_applicable`，附触发判断的原句。自然度是带有主观性的判断，不能用回复字数或问号数量替代。

错误主体、泄露合成私密事实、凭空确定共同经历细节需要单独报告，不能用“整体语气不错”的平均分抵消。认真求助时长一点可以很好；普通招呼反复附带一句自我日程，也可能显得突兀。

候选版本与基线使用相同模型、参数、夹具、时间和历史；记录提交、配置摘要、模型标识、原始请求与输出、Planner 决策、实际生活背景类别和来源。每段先重复生成少量样本观察波动，再对差异明显的段落盲评。初始建议每段运行三次；这只是工作量安排，不是统计充分性的声明。

评分者先看打乱顺序的回复，再查看版本标签。把开发时反复调过的段落标为开发集，另写未见过的改写作为留出集；不要把本语料中的失败描述直接改写成人设提示词。自动评分可辅助发现归属与重复问题，最终的熟悉感仍应保留人工意见。
