# 自己的提醒与主动联系意图

独立的 MaiBot SDK 插件。角色可以通过 `self_reminders` 工具，为自己留下想聊的话、聊完后的补充、等对方有空后的念头或自己的待办，并自主改期、完成、取消、删除。它们属于角色自己的想法，不是用户事实或对方承诺，不写入长期事实记忆。

到期先重新考虑，可以安静结束、延期或提出联系意愿。真正联系仍经过宿主已有的互动预算、暂停/忙碌/未回复退避和原来的 Planner/Replyer。排队不是发送成功；只有平台回执才能确认发送。

## 配置与使用

默认关闭。设置 `enabled=true`、`owner_session` 为已存在、绑定了独占可信关系的 QQ 私聊会话。没有匹配身份或会话就拒绝操作和联系；群聊不能管理或接收这些提醒。不要把 QQ 号直接填入会话 ID。

模型工具支持 `list/create/update/complete/cancel/delete`。新建传 `title`、`kind`、带时区的 `due_at`，可选 `basis`、`cancel_on_reply`；更改或删除用返回的 `id`。`kind` 为 `chat/afterthought/wait_for_user/self_task`，`afterthought` 默认在用户中途发话时取消。重建相近同名提醒会合并；更复杂的语义合并由角色先查看后更新已有条目。

WebUI 的“她自己的提醒”只供查看，没有修改、取消或手动发送按钮。页面显示起因、下次考虑时间、状态与结果。私密资料仍按原有关系和隐私规则处理。

工程默认值：每 60 秒检查，最多 50 个未处理事项，每天最多 8 次内部重新考虑（不是必须联系 8 次）。没有到期事项时不调用模型。02:00–07:00 暂停唤起；联系念头过期窗口 6 小时、自己的待办 7 天；最终记录保留 30 天。时间始终使用配置时区。

普通闲聊沿用宿主原先的间隔。最近 20 分钟内留下的 `afterthought` 允许在双方都安静至少两分钟后补一句；有人忙、明确结束、未回复或达到预算时仍不得绕过边界。其他事项继续遵循原有较长间隔。

网络超时或中断导致是否排队不明确时，状态置为 `uncertain`，不自动重试；可由角色查看并重新决定。未回复达到宿主上限时暂存为 `waiting`，用户再次发话才重新考虑。普通暂停/冷却拒绝则稍后考虑，仍不保证发送。

## 验证与限制

`python -m unittest discover -s tests` 仅使用合成数据，不发 QQ、不调用实际模型。测试覆盖持久化、并发领取、预算、时区、取消、重载、授权与回执。线上安装和工具可用不等于角色已经学会自然使用；主动性与表达效果仍须运行观察。

依赖现有 SDK 与模型路由，没有新增账号、服务或 Python 依赖。由用户自行部署，不属于上游官方插件市场发行。
